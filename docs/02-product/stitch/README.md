# Mirra Stitch prompts (per screen)

## How to use

1. Open Google Stitch project **Mirra — AI Coach UI**.
2. For **each** screen: paste `00-system.md` + that `Sxx.md` (or system once as design rules, then only Sxx).
3. Generate **one artboard at a time** — do not dump all 24 in one prompt (gets text-soup).

## Anti-reference

`ANTI-REF-too-much-text.png` = what **not** to make (pill piles, long headlines, leaderboards, 4-box metrics, promo banners).
