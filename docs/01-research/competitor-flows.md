# Competitor flows (compressed)

Source: [Competitor onboarding flows](094392dc-27cd-4e5d-a6e1-1a1216579a92) — Fitbod, Zing, Freeletics, Cal AI, MFP, Ladder, Future. Full tables live in that agent transcript; this file is the KB slice.

## Pattern every serious app uses

1. Value / demo → long quiz → **building plan** loader → **plan reveal**  
2. Soft or hard **paywall** (annual default, restore, legal)  
3. Home = **today’s action** + week/calendar  
4. Session → summary · Progress charts/photos · Settings/sub manage

## Gaps to consider (v1.1, not blocking Stitch)

| Gap | Competitor | Decision |
| --- | --- | --- |
| Projection screen (% stronger / goal date) before paywall | Fitbod, MFP, Cal AI | Optional **S12b** later — can add line on S12 |
