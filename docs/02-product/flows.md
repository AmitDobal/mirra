# Mirra — flows (complete)

Competitor pattern (Fitbod etc.): long quiz → soft value → paywall after plan tease → tabs. Mirra adds **Mirror→Week** + **check-in / rebuild**.

## Flow count: **10**

| ID | Flow | Entry | Exit |
| --- | --- | --- | --- |
| F01 | First launch / welcome | Cold open | Onboarding |
| F02 | Onboarding quiz + mirror | Welcome Continue | Plan reveal |
| F03 | Auth | After reveal or Settings | Home |
| F04 | Notifications permission | After reveal / Settings | System sheet → next |
| F05 | Paywall / subscribe | Soft gate after Week reveal; hard gate on Pro actions | Home (subscribed) or limited |
| F06 | Today / plan home | Tab Today | Workout / Nutrition / Check-in |
| F07 | Workout session | Start workout | Summary → Today |
| F08 | Nutrition logging | Tab Fuel or log CTA | Today |
| F09 | Daily check-in + rebuild | Push / Coach tab / banner | Rebuilt plan confirm |
| F10 | Progress + settings | Tabs Progress / Profile | Nested editors → back |
